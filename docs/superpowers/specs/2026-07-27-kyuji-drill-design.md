# 旧字ドリル — 設計書

2026-07-27

## 目的

明治〜戦前の日本語文献（近代の活字本・復刻版・青空文庫の旧字旧かな版など）を読むときに
つまずく「今は使われない文字」を、クイズで潰すためのWebアプリ。

対象は**文字**に絞る。古語（古文単語）の意味は扱わない。

## 出題カテゴリ

1. **旧字体・異体字** — 國→国、櫻→桜、辨/辯/瓣→弁 など
2. **変体仮名・合字** — 𛀂(安)、𛂦(者) などの字形と読み。ゟ・〆・ヿ・〳〵 などの記号もここ
3. **歴史的仮名遣い** — けふ→きょう、てふ→ちょう、ゐ/ゑ/を、くわ/ぐわ、ぢ/づ

## 回答方式

- **4択** — 誤答は同カテゴリの他エントリから引く（自然に紛らわしくなる）
- **読み入力** — ひらがなで入力。ゆらぎ（カタカナ・全半角・長音）を正規化して判定

設定でどちらか／混在を選ぶ。

## データ設計（表から自動生成）

問題は手書きせず、3つの表から出題時に組み立てる。表に1行足せば問題が増える。

| 表 | フィールド |
|---|---|
| `kyuji.js` | `old`, `new`, `reading`, `example`, `note?`, `tier` |
| `hentaigana.js` | `char`, `reading`, `jibo`(字母), `tier`, `multi` |
| `kanazukai.js` | `hist`(歴史的), `modern`(現代), `word`, `note?`, `tier` |

`hentaigana.js` は Unicode の `NamesList.txt` の
`* derived from` 注記から機械生成する（`tools/gen-hentaigana.py`）。
字母を記憶で書くと誤りが入るため、一次情報から起こす。
生成対象は U+1B002–U+1B11E の285字。読みが一意でない11字
（A-WO, NI-TE, N-MU-MO など）は `multi: true` を立てて出題プールから外す。

`tier` は 1=よく見る / 2=全部。変体仮名は各音の第1異体字を tier 1 とする。

## 変体仮名の表示

標準フォントに字形がないため、**Noto Serif Hentaigana**（OFL）を
U+1B000–1B11F にサブセットし woff2 で同梱する（79KB）。
`public/fonts/` に置き、ライセンス文 `OFL.txt` を併置。

## 学習管理

- **SRS** — Leitnerボックス（5段階）。正解で1つ上、誤答でボックス1へ戻す
- **ニガテモード** — 誤答回数の多い順に出題
- **カテゴリ別習熟度** — 3カテゴリそれぞれの到達率を表示
- 保存は localStorage のみ（アカウントなし）

## 構成

Vite + 素のJS + Vitest。port 5320。

```
src/core/   純粋関数（quiz / srs / progress / session / storage / data）
src/ui/     描画（home / quizView / resultView / dom）
src/app.js  配線
```

`src/core` はDOMに触れない純粋関数だけで書き、Vitestで固める。
`window.__app` を公開してヘッドレス検証できるようにする。

## テスト

- 4択生成：正解が必ず1つ含まれる／誤答が重複しない／同カテゴリから引く
- 入力判定：カタカナ・全半角・長音のゆらぎ吸収
- SRS：正誤でボックスが正しく動く／出題順が期待通り
- データ整合：`char` の重複なし、`multi` は出題プールに出ない

## やらないこと（YAGNI）

- 実文の一節を読む「実文モード」（カード形式に絞る）
- くずし字（手書き画像）の判読
- 古語の意味
- サーバー・アカウント・同期
